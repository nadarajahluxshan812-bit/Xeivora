XEIVORAMED BRAND KIT
=====================

CONTENTS
--------
/svg                  Vector masters - infinitely scalable, the highest
                      quality format that exists. Use these wherever
                      possible (web, print, apps).

/png/lockup           Full logo with wordmark on deep blue.
                      4800px / 2400px / 1200px wide.
                      Use: website headers, pitch decks, banners.

/png/icon-on-blue     White badge icon (for dark/blue backgrounds).
                      4096 / 2048 / 1024 / 512 / 256 / 128 / 64 / 32 px.
                      Use: app icon, splash screens, dark UI.

/png/icon-on-white    Blue badge icon (for light backgrounds).
                      Same sizes.
                      Use: documents, favicon, light UI, print.

ICON SIZE GUIDE
---------------
1024px  iOS App Store icon
512px   Android Play Store icon
256px   Desktop app icon
64px    Favicon (large)
32px    Favicon (standard)

RULES OF USE
------------
- Never stretch or recolour the mark
- The coral pulse line is the signature - never remove it
- Minimum clear space around the icon: 25% of its width
- On photos or busy backgrounds, use the badge versions only
